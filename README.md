## 🌟 Overview

**EduPath** is a modern educational platform that combines adaptive testing, real-time AI performance insights, and custom curriculum tools for students, teachers, and parents.

### Key Features

- **🎯 Adaptive Test Engine**: Dynamic difficulty scaling based on student responses.
- **📊 AI Performance Analytics**: Deep insights into student mastery, strengths, and areas for improvement.
- **🛡️ Integrity & Cheating Detection**: Advanced detection flags for suspicious test session activities.
- **👨‍🏫 Multi-Role Dashboards**:
  - **Students**: Quizzes, practice sessions, adaptive testing, and achievement tracking.
  - **Teachers**: Question banks, test creation, and student analytics.
  - **Parents**: Progress monitoring and AI-generated summary reports.
  - **Admins**: Content management, system configuration, and bulk question imports.

## 💻 Local Development

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/emadabutaleb0-afk/EduPath.git
   cd EduPath
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Radix UI
- **Routing**: Wouter with SPA GitHub Pages fallback support
- **State & Data**: React Context, Sonner, LocalStorage / In-Memory Mock Database
- **Backend API**: Express router with simulated / PostgreSQL database drivers
